# Core graduation requirements
# ============================
#
# This file is intentionally parallel to MajorMinorRequirements.txt.  It uses
# the existing requirement-tree vocabulary where possible (COURSE_LIST,
# CHOOSE_N, RANGE, TRACK_CHOICE, MANUAL_NOTE), plus core-specific node types
# understood by CoreRequirementProgram and CoreRequirementChecker:
#
#   ATTRIBUTE_COUNT: <attribute> | count: <n>
#   COURSE_COUNT: <n>
#   COURSE_COUNT_FROM_DEPARTMENTS: <dept>|<dept>... | count: <n>
#   DISTINCT_SUBJECTS: count: <n>
#     SUBJECT: <subject-area>
#   DISTRIBUTION: count: <n> | minSubjects: <n>
#     SUBJECT: <subject-area>
#   CREDIT_COUNT: <dept>|<dept>... | credits: <n>
#
# Selection metadata identifies the one core profile that applies to a user.
# The user's canonical major-program key supplies the degree type; campus and
# Jewish-studies track will be supplied by the user profile/selector later.
